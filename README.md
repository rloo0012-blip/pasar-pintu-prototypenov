# Pasar Pintu – WhatsApp commerce prototype

A clickable prototype of a WhatsApp Business-style shop for women produce traders:
catalogue and add-ons, checkout with collection options, community milestones,
chats with automated replies, and a Tools page (insights, active orders, labels, how-to).

It is a single self-contained file (`index.html`), with no build step and no dependencies.
All data in it is sample data.

## Put it online with GitHub Pages
1. Create a new repository on GitHub (public).
2. Upload `index.html`, `.nojekyll` and `README.md` to the root of the repository.
3. Go to **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, then **Save**.
4. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/`.

Use that link for the Canva embed or for a QR code.
